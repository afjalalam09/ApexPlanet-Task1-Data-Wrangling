Data Dictionary - Sales Dataset

1. Row ID (Integer): Unique identifier for each row in the dataset.
2. Order ID (String): Unique identifier for each customer order.
3. Order Date (Date): The date when the customer placed the order.
4. Ship Date (Date): The date when the order was shipped.
5. Ship Mode (String): The shipping method used (e.g., Standard Class, Second Class).
6. Customer ID (String): Unique identifier for the customer.
7. Customer Name (String): Full name of the customer.
8. Segment (String): The market segment the customer belongs to (Consumer, Corporate, Home Office).
9. Country / City / State / Region (String): Geographic location details of the customer.
10. Postal Code (String): The zip/postal code of the customer's location.
11. Product ID (String): Unique identifier for the product.
12. Category / Sub-Category (String): The broad and specific classification of the product.
13. Product Name (String): The descriptive name of the product.
14. Sales (Float): The total sales amount/revenue for the transaction.
15. Shipping Days (Integer): [New Feature] The total number of days taken from order placement to shipping.
